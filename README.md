# STM32迷你智能小车
## 项目简介
基于STM32F103单片机开发的智能小车，具备红外循迹、红外避障功能，可自主沿黑线行驶、识别前方障碍物并规避。
本项目为三创赛参赛作品，使用Keil MDK进行开发。

## 硬件清单
- STM32F103C8T6主控板
- 直流减速电机+电机驱动模块
- 红外循迹传感器
- 红外避障传感器
- 电源模块

## 开发环境
- Keil MDK5
- 编程语言：C语言

## 目录说明
- Code User：用户业务代码
- Core：内核相关文件
- FWLib：STM32标准外设库
- System：系统底层配置
- uVision Project：Keil工程文件

## 使用说明
1. 使用Keil MDK打开uVision Project内的.uvprojx工程
2. 编译工程，烧录hex文件到STM32主控
3. 上电，小车即可启动循迹与避障功能
